Search conditions

start
Finds the start functions, then walks calls from them to the functions that match the end. A call is found by name: `name(` in a function's body (comments and strings left out) links to every function called `name`. Same-named functions all link; calls not written as `name(` (a function passed as a value, a call through a variable) are missed. Default: from a function to the functions it calls. reverse (--step-reverse-to): to the functions that call it. --hops limits how many calls away an end may be. For exact relations, start --serve with --edges=FILE.

Details


how strict a match must be (--level): loose takes more lines, strict fewer


-t: a line matches when its probability is at least this (0 to 1)
-T: a negated meaning holds when the probability is below this (0 to 1)


-C: lines of context before and after each match


-A: lines of context after each match (trailing only)
-B: lines of context before each match (leading only)


--auto-scope: narrow the files by what Jev says the meaning restricts to (a language, a kind of file); off is --no-auto-scope


-n: show line numbers
-p: show the probability of each meaning on the matching lines


--dedup: judge one line per template (lines that differ only in ids, numbers, dates) and reuse the answer; auto does it when it pays


--unit: what one question judges: a line, a sentence (found by Jev or by a rule), or a function (git grep -W's boundaries). A multi-step walk is by function regardless of this. zero (-z, same as --unit=zero) is refused here, like -z itself


-o: with a sentence unit, print only the matching sentences, not the whole line


-j: concurrent requests to the API
--max-cost: ask before sending when the estimated price is over this many USD


--include: only file names matching these globs, space separated. Applies to -r and git sys1grep; it narrows the launch targets, never widens them
--exclude: not file names matching these globs, space separated. Applies to -r and git sys1grep


--changed-within: only files modified within 30m, 2h, 7d, 2w, or since a date. Applies to -r and git sys1grep
-g: search git log's commits, one record each
